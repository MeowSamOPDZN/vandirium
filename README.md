# Vandirium

Vandirium, your personal AI assistant powered by MNAI 6, by MeowSamOPDZN Studio.

Meet Vandirium, your personal AI assistant. Chat with MNAI 6, create images in the Image Studio, and let the Vandirium desktop agent work on your PC for you.

**Website:** https://vandirium.vercel.app/ (launching soon)
**Desktop app:** [Vandirium Desktop](https://github.com/MeowSamOPDZN/vandirium-desktop)

## What it does

- **Chat** — talk to MNAI 6, a model by MeowSamOP DZN (Meow x Nythera AI). Ask, write, plan, research, learn.
- **Image Studio** — create and edit images with Sketch and Text tools.
- **Desktop agent** — the Vandirium desktop app can control the browser, desktop screen and input, local apps and files, and PowerShell, once you grant task permission inside Vandirium.

## Desktop app

Download the Windows installer from the
[releases](https://github.com/MeowSamOPDZN/vandirium/releases).
It installs to Program Files, adds Start Menu and desktop shortcuts, and
registers an uninstaller. The desktop app loads the live site, so it stays
current without rebuilding the installer. No auto-updater.

The desktop agent bridge is in the
[vandirium-desktop](https://github.com/MeowSamOPDZN/vandirium-desktop)
repo.
